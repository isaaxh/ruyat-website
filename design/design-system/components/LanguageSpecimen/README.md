# LanguageSpecimen

The full type specimen: every type style in `tokens.json`, set in its own language and font — Arabic (Tajawal), English (Plus Jakarta Sans), Urdu (Noto Nastaliq Urdu) and Bangla (Hind Siliguri) — with its size, leading and weight.

- **Provide** nothing — it is a reference, not a reusable component. The Typography tab shows a fixed English line for every style; check real-language rendering here.
- To localize a view, set `lang` and `dir` on its root (`ar`/`rtl`, `en`/`ltr`, `ur`/`rtl`, `bn`/`ltr`); `bundle.css` switches family and leading.
- Urdu and Bangla sample lines are draft translations; have a native speaker confirm them before publishing.
