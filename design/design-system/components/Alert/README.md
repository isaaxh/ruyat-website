# Alert

An inline message after an action: an error above a form that failed, or a confirmation.

- **Markup:** `div.ra-alert.ra-alert--danger[role="alert"]` or `.ra-alert--success[role="status"]` › icon `ra-ico` + `p.ra-alert__text`.
- Border and icon in `danger` or `success`, tinted ground (`danger-tint`, `success-tint`), text stays `ink`. `radius-md`.
- Say what happened and what to do next, in one or two sentences; no exclamation marks.
