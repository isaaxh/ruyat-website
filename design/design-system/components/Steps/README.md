# Steps

The numbered "How it works" list on a Service Detail page: gold numbered circles joined by a gold line.

- **Markup:** `ol.ra-steps` › `li.ra-step` › `div` with `h3.ra-step__title` + `p.ra-step__text`. Numbers come from CSS, in Latin digits.
- 3–5 steps, titles of two to four words. Circles 40px `accent-fill`, line 2px `rule`.
