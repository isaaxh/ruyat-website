# ServiceGrid

A grid of services, each a gold line icon above its name, separated by gold hairlines: the layout of the roll-up banner and the «تعرّف على خدماتنا» post.

- **Provide** 3, 6 or 9 items, each an outline icon (24×24 viewBox, stroke only) and a service name of one to four words. Markup: `.ra-services` > `.ra-service` > `svg` + `span`.
- Icons stroke in `accent` at 1.5px, `size-icon-lg` (48px); names in `ink`, 18px / 700. Lines are 1px `rule`. 2 columns on mobile, 3 from 641px. Inside `.ra-navy` icons turn `accent-on-navy` and names white.
- For print and social posts. On the website use ServiceCard, which links to each service.
- Order services as the brand lists them, starting at the reading start: تأسيس الشركات، التراخيص الاستثمارية، الخدمات الحكومية، خدمات المستثمرين…
- The icons in the preview are stand-ins (see Iconography); swap in the brand's own when supplied.
