# Testimonial

A white card with five gold stars, the quote, and the client's initials, name and role.

- **Markup:** `figure.ra-quote` › `.ra-quote__stars` (five filled star `ra-ico`, plus `ra-sr-only` "5 out of 5") › `blockquote.ra-quote__text` › `figcaption.ra-quote__by` (`.ra-avatar` initials, `.ra-quote__name`, `.ra-quote__role`).
- `radius-lg`, `shadow-card`, padding `space-6`, on an ivory band. One card at a time on mobile (swipe + `ra-iconbtn` arrows in `.ra-carousel__nav`), 2 on tablet, 3 on desktop.
- Quote `body`, name 14px / 800, role `caption`. Use real client quotes only, with permission; initials, never stock photos.
