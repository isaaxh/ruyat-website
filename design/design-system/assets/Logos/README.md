# Logos

Arabic only (no Latin/English version). The website uses the SVGs; PNGs are for other uses.

| File | What it is | Use on |
|---|---|---|
| `ruyat-logo-primary.svg` / `.png` | Mark + name + tagline «لخدمات الأعمال» + gold separator + slogan «من الفكرة .. إلى الإنجاز» | Light backgrounds |
| `ruyat-logo-primary-white.svg` / `.png` | Same, white name and slogan | Navy backgrounds |
| `ruyat-logo-secondary.svg` / `.png` | Mark + name + tagline (no slogan) | Light backgrounds |
| `ruyat-logo-secondary-white.svg` / `.png` | Same, white name | Navy backgrounds |
| `ruyat-logo-name-only.svg` / `.png` | Mark + name | Light backgrounds |
| `ruyat-logo-name-only-white.svg` | Same, white name | Navy backgrounds |
| `ruyat-logo-submark.svg` | Gold mark alone. Website and favicon only (SVG only) | Light or navy |

Rules: the tagline and separator always stay gold; the name and slogan switch between navy (`#041238`) and white. The gold is a baked-in gradient: never recolour, outline, stretch or re-set the wordmark in a font.
